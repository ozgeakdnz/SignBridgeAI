# Telefon mockup ekran görüntüleri

Bu klasöre gerçek uygulama screenshot’larını koyun. Landing otomatik kullanır.

| Dosya | Ekran |
|--------|--------|
| `kopru.webp` | Köprü |
| `guvenlik.webp` | Güvenlik |
| `yakinlarim.webp` | Yakınlarım |
| `topluluk.webp` | Topluluk |

Dosya yoksa CSS mock UI gösterilir (`onerror` ile img kaldırılır).
PNG de olur: `kopru.png` kullanacaksanız `landing-body.html` içindeki `.webp` uzantısını değiştirin.
